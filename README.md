# PSoC5LP CY8KIT-059 FreeRTOS basic single-task example
This repository contains a demonstration project showing how to use FreeRTOS on the CY8CKIT-059 development board.

## Used Software

* PSoC Creator 4.4
* FreeRTOS Kernel Repo: https://github.com/FreeRTOS/FreeRTOS-Kernel/tree/V11.3.3
* Empty App CE

## Steps to reproduce
* Clone this repository.
* Open the project in PSoC Creator 4.4.
* Connect an external LED with a current-limiting resistor to pin P0.0.
* Build the project and program the CY8CKIT-059 board.
* Observe the LED blinking after successful programming.
